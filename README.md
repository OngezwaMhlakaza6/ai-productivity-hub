# AI Productivity Hub

Build a modern, responsive SaaS web app called AI Workplace Productivity Assistant.

Create a clean professional black and purple dashboard with a sidebar navigation and responsive layout.

Features

1. Smart Email Generator

User enters the purpose/details of an email.

Generate a complete professional email using AI.

Tone options: Formal, Friendly, Persuasive.

AI-generated output must be editable.

2. Meeting Notes Summarizer

User pastes lengthy meeting notes.

AI generates a concise summary.

Automatically extract:

Key decisions

Action items

Deadlines

AI-generated output must be editable.

3. AI Research Assistant

User can enter a topic or paste an article/website URL.

AI summarizes the content and provides:

Key insights

Important findings

Practical recommendations

AI-generated output must be editable.

UI/UX

Modern SaaS-style dashboard.

Black and purple visual theme.

Sidebar navigation for the three tools.

Clean cards, buttons, forms, and output sections.

Fully responsive for desktop, tablet, and mobile.

Include loading states and clear error messages.

AI Behavior

All generated content must be AI-generated and context-specific, not generic placeholder responses. Use structured AI prompts appropriate to each tool.

Data & Privacy

No backend.

Do not store, save, or persist user data.

No database, accounts, or authentication.

Process inputs only for the current session/request.

Include a small Responsible AI disclaimer stating that AI-generated content may contain errors and should be reviewed before professional use.
